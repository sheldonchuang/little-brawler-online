# 🥊 熱血格鬥連線 (Little Brawlers Online)

致敬《熱血物語》(River City Ransom) 與《小朋友齊打交 LF2》(Little Fighter 2) 的 2.5D 線上多人格鬥網頁遊戲 / PWA APP。

---

## 🎮 遊戲特色

- **經典 2.5D 橫向捲軸軸線打擊**：具備 X 軸走位、Z 軸景深、Y 軸跳躍與擊飛重力系統。
- **純原創零外部依賴**：完全採用 Node.js 核心內建 HTTP 與 RFC 6455 原生 WebSocket，免繁雜安裝、開箱即跑。
- **即時多人上網連線**：
  - 輸入相同房間代號（如 `ARENA-1`）即可與朋友跨設備對戰！
  - 支援房內多人 PvP 與共同打擊敵人。
- **AI 雜兵 / 假人樁系統**：
  - 即使只有 1 個人，也能點擊「🤖 召喚對手」召喚黑帶混混、重裝大牛等 AI 小兵練習連招或雙人合作闖關！
- **Web Audio 8-bit 合成音效**：
  - 揮拳呼嘯、重擊爆破、氣功爆裂、倒地重擊、KO 歡呼聲，全部透過瀏覽器晶片合成，無需加載外部 mp3 檔案。
- **跨平台支援（電腦鍵盤 + 手機觸控）**：
  - 電腦端支援經典 LF2 鍵位操作與雙擊衝刺。
  - 手機端自動啟動虛擬類比搖桿與動作大按鈕，並支援 PWA 安裝至手機主畫面。

## 🚀 快速啟動

專案目錄位於：
`/Users/sheldonair/.gemini/antigravity/scratch/little-brawler-online`

在終端機執行：
```bash
node server.js
```

### 進入遊戲網址：
- **本機電腦遊玩**：打開瀏覽器訪問 [http://localhost:3000](http://localhost:3000)
- **同區域網路連線（手機 / 朋友電腦）**：
  打開瀏覽器訪問 `http://192.168.0.38:3000`（或你的本機 IP + `:3000`）

## 🕹️ 遊戲操作指南

### 💻 電腦操作
| 動作 | 鍵位 |
| :--- | :--- |
| **移動 (八向)** | `W`, `A`, `S`, `D` 或 `↑`, `←`, `↓`, `→` |
| **衝刺疾跑** | 雙擊 `A` / `D` 或按住 `Shift` |
| **普攻連招** | `J` 或 `Z`（三連擊：刺拳 ➔ 直拳 ➔ 昇龍重拳） |
| **跳躍 / 空中飛踢** | `K` 或 `Space`（跳起後按 `J` 發動飛踢） |
| **必殺絕招 (消耗 MP)** | `L` 或 `C`（各角色專屬氣功彈 / 冰晶 / 裂地波） |
| **格擋防禦** | `U` 或 `V`（減免 80% 傷害並免疫硬直） |
| **發送聊天** | 按 `Enter` 鍵輸入文字或點擊表情快捷鍵 |

### 📱 手機操作
- **左側搖桿**：拖動控制八向移動，向外推滿自動進入衝刺疾跑。
- **右側按鈕**：
  - 👊 **攻**：連續點擊發動組合拳。
  - 🦘 **跳**：跳躍，空中按「攻」可發動飛踢。
  - ⚡ **技**：消耗 MP 施放角色專屬絕招。
  - 🛡️ **防**：按住防禦，減免大幅傷害。
  - 💨 **閃**：單擊立即進行高速衝刺。

## 🤼 角色介紹

1. **赤焰 (Davis / 國夫風格)**：
   - 特色：全能拳擊型，昇龍拳 finisher。
   - 絕招：**波動氣功拳**（高速向前發射高傷害火球）。
2. **疾風 (Dennis / 冰人格鬥家)**：
   - 特色：高移速連環踢法。
   - 絕招：**追蹤冰晶彈**（雙發冰晶飛彈，打擊範圍廣）。
3. **阿豪 (Titan / 重裝豪鬼)**：
   - 特色：150 超高生命值霸體猛男。
   - 絕招：**巨岩裂地衝**（敲擊地面掀起衝擊震波，擊飛前方範圍敵人）。
